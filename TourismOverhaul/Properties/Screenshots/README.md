# Screenshots

Drop store screenshots here, then uncomment the matching `<Screenshot>` lines in
`../PublishConfiguration.xml`.

Suggested set, in the order they should appear on the store page:

1. `01-tourism-panel.png` — the Tourism info view showing the added rows
   (Tourists in city, Hotel rooms free, Local cims away)
2. `02-settings.png` — the mod's settings page
3. `03-arrivals.png` — tourists arriving at an airport or harbour

Capture at the game's native resolution and avoid cropping the panel edges. The publisher
resolves these paths relative to its working directory, so run it from the managed project
directory or use absolute paths.
